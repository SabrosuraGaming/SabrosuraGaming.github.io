Privacy Policy

Last updated: November 13, 2026

Sabrosura Gaming Uploader ("the app") is a personal tool used only by the owner of the Sabrosura Gaming YouTube channel to upload his own videos.

Data we access

With the user's permission through Google's sign-in, the app uses the YouTube Data API to upload videos and read basic channel information (channel ID, title and handle) to confirm the correct channel.

How data is stored

Access tokens are stored only on the owner's own computer. The app does not collect, sell, share or transfer any user data to third parties, and it does not use data for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

You can revoke the app's access at any time at Google Account permissions.
